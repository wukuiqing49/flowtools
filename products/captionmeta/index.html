Product purpose

What CaptionMeta helps you do

CaptionMeta brings photo capture, metadata editing and delivery preparation into one Android workflow. Photographers can add useful context while a shoot is still fresh instead of postponing every metadata task until they return to a computer.

Reusable presets and batch editing help keep captions, keywords and ownership information consistent across a set of images. The result is a clearer handoff for upload, client delivery or long-term archiving.

Core metadata work is performed on the photos selected on the device, making CaptionMeta useful for offline field preparation. A network connection is only relevant when the finished files are uploaded, shared or sent to an external destination.

FAQ

Frequently asked questions

What metadata does CaptionMeta support?

CaptionMeta is designed for IPTC, EXIF and XMP workflows, including captions, keywords and photo information.

Is it suitable for field photography?

Yes. Capture, presets and batch editing are designed to reduce repetitive metadata work away from the desk.

Can CaptionMeta edit metadata offline?

Core editing works with photos selected on the Android device and does not require a cloud catalog. Uploading or delivering files to an external service may require a network connection.

Can I apply metadata to multiple photos?

Batch editing and reusable values are designed to keep captions, keywords and ownership information consistent across a selected set.

Where can I install CaptionMeta?

CaptionMeta is available for Android through Google Play.
