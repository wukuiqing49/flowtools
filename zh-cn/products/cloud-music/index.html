产品用途

Cloud Music 能帮你完成什么

Cloud Music 在简洁的 Android 音乐库中连接本地歌曲与用户选择的云端音乐来源，艺术家、歌单和设备音乐等常用入口都能通过较少的导航步骤到达。

它面向已经拥有个人音乐收藏、希望使用专注播放器而非订阅曲库的用户。本地扫描负责发现兼容文件，云端访问则作为由用户主动选择的独立来源。

设备中已经保存的音乐可以通过本地音乐库整理并离线播放，无需打开云端来源。当所选收藏保存在远程位置，或外部来源要求账号访问时，则需要网络连接。

歌单导航

FAQ

常见问题

Cloud Music 可以播放本地文件吗？

可以，应用提供本地音乐库和设备扫描入口。

可以管理艺术家和歌单吗？

可以，艺术家与歌单都有独立的音乐库视图。

可以离线听歌吗？

设备中已保存的兼容音乐可以从本地音乐库离线播放；远程收藏需要网络连接。

Cloud Music 提供订阅曲库吗？

Cloud Music 面向你已经保存在本地或通过自定义来源访问的音乐，不是内置订阅曲库。

在哪里安装 Cloud Music？

Cloud Music 已通过 Google Play 提供 Android 版本。
